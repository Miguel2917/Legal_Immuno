## Idiomas disponibles

Todas las páginas incluyen un selector de idioma en la parte superior y detectan automáticamente el idioma del navegador (con respaldo en español si JavaScript está desactivado). También se puede enlazar directamente a un idioma mediante `?lang=`:

- `es` — Español (Latinoamérica)
- `en` — English (Estados Unidos, Canadá, Australia, Nueva Zelanda, India, Singapur, Filipinas, Malasia, Nigeria, Ghana, Tanzania, Uganda)
- `pt` — Português (Brasil)
- `fr` — Français (Canadá / Quebec, Suiza)
- `ja` — 日本語 (Japón, incluye 「特定商取引法に基づく表示」 en `terms.html?lang=ja#vendedor`)
- `ko` — 한국어 (Corea del Sur)
- `id` — Bahasa Indonesia (Indonesia)
